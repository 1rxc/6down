# 6Down Studio - YouTube MP4 & MP3 Downloader

High quality, clean YouTube video & audio converter built with FastAPI, yt-dlp, and FFmpeg.

## Free Deployment Options

### 1. Hugging Face Spaces (100% Free - 16GB RAM, 2 vCPU, 50GB Disk)
1. Go to [huggingface.co/new-space](https://huggingface.co/new-space)
2. Choose **Docker** as the Space SDK (Blank template).
3. Upload or git push this repository.
4. Your app is live with free HTTPS and unlimited usage!

### 2. Render.com (Free Web Service)
1. Push this folder to your GitHub.
2. Go to [render.com](https://render.com) and create a **New Web Service**.
3. Select your repository and choose **Docker**.
4. Set plan to **Free**.

### 3. Share with Cloudflare Tunnel from your PC (100% Free Forever)
Run `share-free.bat` to instantly generate a secure, free public `https://....trycloudflare.com` link for family and friends directly from your computer without port forwarding!
